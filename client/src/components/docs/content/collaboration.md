# Collaboration and teams

## Realtime

Everyone with access sees each other's cursors and avatars, and changes appear live. If the connection drops, the editor reconnects and keeps your local changes.

## Sharing

Open Share on a file to:

- turn on a **public link** with *view* or *edit* access (turn it off any time)
- **invite people by email** as viewer or editor (they need an account)
- mark the file **private** so only the owner and invited people can open it

Files in a workspace are visible to its members unless they are private. Guests only see files shared with them explicitly.

## Comments

Add comments on the canvas or on a selected element, reply in threads, resolve when done, and delete your own. Pins appear as numbered markers.

## Version history

easydraw snapshots a file automatically (at most every five minutes while you edit) and whenever you press Ctrl/⌘+S. Preview any version and restore it; restoring snapshots the current state first.

## Folders, search, trash

Organise files in folders, search by title, duplicate a file, and move files to the trash. Trash can be restored or emptied permanently.

## Teams and roles

Every account has a personal workspace and can belong to more teams. Roles:

| Role | Can do |
| --- | --- |
| Owner | everything, including role changes |
| Admin | manage members, domain and audit log |
| Member | create and edit files |
| Guest | open files shared with them |

Invite by email from **Team**. Set an **allowed email domain** and anyone signing up with that domain joins automatically. The **audit log** records sign-ins, file and sharing changes, member changes and token activity.
