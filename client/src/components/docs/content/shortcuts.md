# Keyboard shortcuts

On macOS use ⌘ where this page says Ctrl.

## Tools

| Key | Tool |
| --- | --- |
| V | Select |
| H | Hand (pan) |
| P | Pen |
| E | Eraser |
| N | Sticky note |
| T | Text |
| R | Rectangle |
| O | Ellipse |
| D | Diamond |
| A | Arrow |
| I | Image |

## Actions

| Shortcut | Action |
| --- | --- |
| Ctrl+Z | Undo |
| Ctrl+Shift+Z | Redo |
| Ctrl+D | Duplicate selection |
| Delete / Backspace | Delete selection |
| Ctrl+S | Save a named version |
| Ctrl+K | Command search |
| Ctrl+/ | Toggle the diagram code panel |
| Ctrl+0 | Reset zoom |
| Ctrl + scroll | Zoom |
| Space + drag | Pan |
